Key Features

YaleSites is a free service available to the Yale community — to conduct University business, there’s no cost to get started or to maintain your site.

You don’t need to be a developer to build a great-looking site. YaleSites offers a user-friendly design experience that lets you create and manage pages without writing any code — so you can focus on content, not complexity.

The Layout Builder gives you full control over how your content is displayed. Use drag-and-drop tools to structure pages, insert reusable components like text, images, and more, and adjust layouts with ease — all within a visual interface. Build pages quickly by adding content blocks, which allow for flexible design and simple updates.

Accessibility is built into the foundation of YaleSites. The platform meets WCAG standards to ensure content is usable by everyone — including individuals with disabilities — helping you create a more inclusive online experience. The platform integrated Editorially tool provides accessibility checks as you create content, so you can easily ensure your site is compliant.

Each site created with YaleSites is automatically styled to align with Yale’s official branding. That means you get a polished, professional look that represents the university’s identity — without the need to manage brand guidelines yourself.

YaleSites is constantly improving. You’ll benefit from regular updates, new features, and platform enhancements that keep your site secure, functional, and aligned with the latest web best practices — all without lifting a finger. Our development team is always working on the roadmap, ensuring new releases and features meet your evolving needs. Stay up-to-date with the latest changes and improvements as we continue to enhance the platform.
